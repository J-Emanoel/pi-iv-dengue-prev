# Registro de uso de IA

Registrar solicitações relevantes para arquitetura, código, testes,
tratamento de dados, modelagem ou refatorações. Perguntas operacionais
triviais não precisam de arquivo próprio.

Usar nomes como `AAAA-MM-DD-assunto.md`, contendo:

- Data e ferramenta utilizada.
- Pedido ou síntese fiel, identificada como síntese.
- Contexto e arquivos considerados.
- Decisões e arquivos produzidos.
- Verificação realizada e limitações pendentes.

Não registrar segredos, tokens, senhas ou amostras individuais de saúde.
O registro documenta a contribuição da IA. A revisão técnica e acadêmica
deve considerar o código e os resultados efetivamente verificados.
